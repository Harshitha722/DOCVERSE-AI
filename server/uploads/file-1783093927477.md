```mermaid
graph TD

        direction TB
        User([🧑‍💼 Business User]) --> |Uploads Transcripts/CRM Data| UI[Next.js Dashboard UI]
        UI --> |POST /analyze| API_Gateway[FastAPI Backend]
    end
    class UI frontend;
    class User human;

    %% 2. CONTEXT & ROUTING LAYER
    subgraph Context ["🧠 Context & Routing Layer (FastAPI)"]
        direction TB
        API_Gateway --> |Detects Domain| Ontology[YAML Ontology Engine]
        API_Gateway --> |Embeds Text| QdrantRAG[(Qdrant Vector DB: Context)]
        API_Gateway --> |Fetches History| QdrantMemory[(Qdrant Vector DB: Memory)]
    end
    class API_Gateway backend;
    class Ontology backend;
    class QdrantRAG database;
    class QdrantMemory database;

    %% 3. AGENTIC ORCHESTRATION LAYER
    subgraph Orchestration ["🤖 Parallel Agentic Layer (Pydantic-AI)"]
        direction TB
        Ontology --> |Domain Detected| Factory[Dynamic Agent Factory]
        Factory --> |Spins up Agents| Registry[Runtime Agent Registry]
        
        Registry --> |Async Parallel Execution| Agent1[Opportunity Agent]
        Registry --> |Async Parallel Execution| Agent2[Risk & Blockers Agent]
        Registry --> |Async Parallel Execution| Agent3[Financial Agent]
        
        QdrantRAG -.-> |Injects Facts| Agent1 & Agent2 & Agent3
        QdrantMemory -.-> |Injects Past Learnings| Agent1 & Agent2 & Agent3
        
        Agent1 & Agent2 & Agent3 <--> |Reasons via| Gemini((Google Gemini 1.5 Flash))
    end
    class Factory ai;
    class Registry ai;
    class Agent1 ai;
    class Agent2 ai;
    class Agent3 ai;
    class Gemini ai;

    %% 4. SYNTHESIS & HUMAN LAYER
    subgraph Synthesis ["⚖️ Synthesis & Human-in-the-Loop"]
        direction TB
        Agent1 & Agent2 & Agent3 --> |Returns Strict JSON| Synthesizer[Recommendation Synthesizer]
        Synthesizer --> |Drafts Report| Confidence[Confidence Engine & Critique]
        Confidence --> |If Score < 70%| HitL{Mandatory Human Review}
        HitL --> |Approve / Override| FinalReport[Final Decision Report]
        
        FinalReport --> |Displays Next Best Action| UI
        FinalReport --> |Saves Outcome for Future| QdrantMemory
    end
    class Synthesizer backend;
    class Confidence backend;
    class HitL human;
    class FinalReport backend;

```
